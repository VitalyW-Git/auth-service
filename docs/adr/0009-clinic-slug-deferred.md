# 0009. `clinics.slug` отложен до публичной страницы записи

- **Статус:** принято
- **Дата:** 2026-10-11

## Контекст

В макетах есть адрес публичной страницы записи `[домен]/c/dentalux-central` и атрибут виджета
`data-clinic="dentalux-central"`. Первая версия схемы расписания содержала `clinics.slug`.

## Решение

`slug` не добавляется в схему раздела «Расписание». Кабинет доступен только авторизованным сотрудникам,
клиника там определяется по `clinic_members` и `id`; человекочитаемый адрес нужен только публичной части
(страница записи, виджет). Колонка добавляется вместе с этим разделом.

## Последствия

В `clinics` к тому моменту будут строки, поэтому миграция будет трёхшаговой: добавить колонку как nullable,
заполнить из названия (`dentalux-central`), затем `not null` и уникальность `clinics_slug_unique`.

## Отвергнутые варианты

- **Добавить сразу.** В каждой миграции должно быть только то, что использует её раздел.
